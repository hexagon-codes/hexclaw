# 经核验的同题来源关联

`POST /api/k12/review-source-groups`记录已审核的同题来源，供错题卷和周练的只读出卷归并使用。沿宿主K12 API认证，不新增页面或投递入口。

请求字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `agent` | string | 来源所属辅导实例 |
| `canonical_record_id` | string | 成员中已有的代表错题记录 |
| `members` | array | 至少两个不同记录，每个明确选择一份冻结输入回执 |
| `members[].record_id` | string | 原错题记录ID |
| `members[].job_id` / `problem_id` / `attempt_id` | string | 完整来源元组 |
| `members[].confirmed_version` / `input_revision` | integer | 选择的确认版本与已发布输入修订，均大于0 |
| `members[].input_digest` / `result_digest` | string | 原冻结输入与结果摘要，不更改既有摘要格式 |
| `evidence.kind` | string | 固定为`reviewed_sources`，表示已有显式来源审核 |
| `evidence.note` | string | 非空审核依据，说明为何是同一完整作答目标 |

服务端核对原记录、全部已发布输入和页来源，派生题面摘要、原图摘要、父子题号与代表题面。客户端不能提交自编题面、答案或页摘要。仅支持能匹配完整原题的照片批改来源；不执行求解、评分、掌握更新或消息投递。

响应：`{"group": {...}, "created": true, "replayed": false}`。`group`包含稳定`group_id`、`canonical_statement`及其摘要、全部`members`和审核依据。成员中的`question_digest`只覆盖原题文字，不包含学习状态或到期时间。

组身份由实例、代表记录和完整成员身份确定，不把派生题面或审核说明作为新组依据。相同请求在题面清理规则升级后重试仍返回首次冻结的副本。不同新组若接管仍有效旧组的成员则返回409；旧组失效后可记录新的审核关系。

| 状态码 | 含义 |
|---|---|
| 201 | 首次原子保存关联 |
| 200 | 同一身份重放，返回首次冻结的组、审核说明和时间 |
| 400 | 请求结构、审核依据或成员集合无效 |
| 404 | 原记录不存在或不属于指定实例/错题集 |
| 409 | 输入未发布、来源已变化，或与仍有效的其他审核组重叠 |
| 500 | 存储或其他内部错误 |

关联为追加事实。原错题和旧PDF不改写。任一成员版本或原题失效时，出卷忽略整组，继续保留原题；学习状态或到期时间变化不会使关联失效。没有显式审核的近似题不据此自动合并。该接口不表示答案已经通过验证，也不提供通用Skill安装或A11文字解题结算。
