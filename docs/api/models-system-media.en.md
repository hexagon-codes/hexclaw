# Models, system and media API reference

[API overview](../api.en.md) · [中文](models-system-media.md) · [OpenAPI](../../api/openapi.yaml)

This reference covers 53 registered method/path combinations in the current source, including conditional modules and native internal endpoints. A released binary may differ; use the documentation matching its version. Requests and responses below define the public contract; implementation links are supplementary.

## Before calling

- Except for `GET /health` and `GET /api/v1/version`, business endpoints use `Authorization: Bearer ${HEXCLAW_API_TOKEN}`. Read the token generated by your service configuration; never put it in URLs. Native endpoints use a different capability and also require loopback.
- JSON requests use `Content-Type: application/json`. Audio uploads, audio responses, generated file downloads, SSE, WebSocket and plain-text handler errors use the content types specified per operation.
- Required means required in a request or present in a response; defaults apply only where explicitly documented. Nullable patches preserve values on omission/null where stated. Referenced schemas below list all declared fields, including nested objects; arbitrary maps occur only for actual provider-specific or log data.
- Conditional modules are not mounted without their service: capability cache, STT/TTS, budget and desktop host routes then have no matching route. Other media status routes remain available and report `enabled:false`; generation returns 503 if unconfigured.
- Health reports process health, not model readiness. Probe/generation operations may call an upstream provider and incur cost. HTTP 200 or a submission task ID does not establish complete artifact delivery.

```bash
export HEXCLAW_API="http://127.0.0.1:16060"
export HEXCLAW_API_TOKEN="REPLACE_WITH_YOUR_SERVICE_TOKEN"
```

Example identifiers and responses are illustrative. Replace `REPLACE_WITH_*` with values returned by your service and a model supported by the selected provider. State-changing examples explicitly describe their side effects; do not replay an unknown upstream outcome blindly.

### PUT `/api/v1/config/llm` — Update LLM configuration

Authentication: `Authorization: Bearer ${HEXCLAW_API_TOKEN}`.

Availability: `always registered`.

1 MiB JSON. providers omission/null preserves; a map replaces the complete set. model_specs omission/null preserves declaration mode; [] is explicit unclassified. Empty default preserves; selected default requires text. Supply both conditions together. Key and mutation are mutually exclusive; preserve requires existing identity, replace requires native hydration, delete clears. Only a masked **** key preserves the old key; ordinary empty key does not. Successful persistence hot-reloads runtime. Conflicting idempotency content is 409; reconcile unknown outcomes via receipts.

| Field | Type / contract | Required | Defaults / constraints | Meaning |
